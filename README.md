# bankguard

死锁避免的资源账本工作台（原生 ES 模块，零依赖）：三类资源 A、B、C 各有总量，四个进程申报最大
需求，申请先做试分配，再从新的可用向量出发按进程号从小到大做安全扫掠，扫不完就整笔撤回并记
一条拒付。

页面把状态画成库存尺：每条尺上格子是该进程占用的份数，末端是可用份数，尺尾印着已分配加可用
是否等于总量；下面一条是最近一次审计或受理的扫掠顺序；最下面是逐笔事件流水与记账台。

## 起服务看页面

    python3 -m http.server 8000

浏览器打开 http://127.0.0.1:8000/ 即可记账。

## 测试

    node tests/run.js

## 场景自检

    node check_sample.js
